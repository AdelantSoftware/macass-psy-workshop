# MACASS Psy Workshop — Il Percorso delle Sei Parole

## PROMPT DEL PERCORSO IMMERSIVO WORKSHOP PSICOLOGIA

Web app immersiva e interattiva per un festival culturale.
Obiettivo: accompagnare i visitatori in un percorso esperenziale composto da sei tappe distribuite fisicamente all'interno del festival.

---

## 1. SCHERMATA DI BENVENUTO

- **Titolo:** "Il Percorso delle Sei Parole"
- **Introduzione:** "Ogni esperienza rappresenta una tappa del tuo viaggio. Durante questo percorso incontrerai sei parole. Per scoprirle dovrai esplorare il festival, trovare i sei QR Code nascosti e affrontare le sfide che ti accompagneranno verso una maggiore consapevolezza."
- **Pulsante:** "Inizia il viaggio"

## 4. LE SEI TAPPE

Ogni tappa viene sbloccata solamente dopo aver scansionato il QR Code fisico corrispondente.
Ogni QR Code identifica una sola tappa.

### Tappa 1 — "ASCOLTA"
- **Luogo:** Casa MAC
- **Esperienza:** Una grande ruota delle emozioni che gira
- **Interazione:** Una volta fatta girare la ruota e uscita l'emozione → esce la parola **"ASCOLTA"**

### Tappa 2 — "ACCETTA"
- **Luogo:** Casa MAC
- **Esperienza:** Un'agenda troppo piena da liberare di impegni
- **Interazione:** Una volta liberata l'agenda dagli impegni → esce la parola **"ACCETTA"**

### Tappa 3 — "RESPIRA"
- **Luogo:** Casa MAC
- **Esperienza:** Un peluche che chiede un abbraccio
- **Interazione:** Una volta completato l'abbraccio → esce la parola **"RESPIRA"**

### Tappa 4 — "SEI"
- **Luogo:** Libreria 100 Pagine
- **Esperienza:** Un piccolo gioco di memory
- **Interazione:** Una volta completato il gioco → esce la parola **"SEI"**

### Tappa 5 — "GIÀ"
- **Luogo:** Mostra
- **Esperienza:** Due navi che si incontrano in un porto
- **Interazione:** Una volta che le navi si sono incontrate → esce la parola **"GIÀ"**

### Tappa 6 — "ABBASTANZA"
- **Luogo:** Mostra
- **Esperienza:** Una bilancia dove a sinistra ci sono i giudizi e a destra le qualità
- **Interazione:** Una volta eliminati tutti i giudizi → esce la parola **"ABBASTANZA"**
